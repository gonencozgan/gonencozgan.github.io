# gonencozgan.github.io

Public web pages of Tontiş and Menia, published with GitHub Pages from
the `gonencozgan.github.io` repository. Each app keeps the source in its
own repository under `store/site/`; edit it there and publish again
(docs/yayin.md, "Web sitesi").

- `menia/`: Menia's landing page, privacy policy (`menia/gizlilik/`),
  four calculator pages and `menia/sitemap.xml`.
- `robots.txt`: points search engines to the sitemap.

- `app-ads.txt`: AdMob seller declaration; must stay at the site root.
- `tontis/gizlilik/`: privacy policy (Play Console and AdMob link here).
- `tontis/vaccine-schedule.json`: the vaccine schedule the app checks
  weekly (`VACCINE_SCHEDULE_URL`).
